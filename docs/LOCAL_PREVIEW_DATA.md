# Заполненная локальная версия

По явному указанию пользователя данные тестовой книги загружены для просмотра в локальную базу `zra` на 127.0.0.1:55432. Источник не изменён. Сначала сделана резервная копия; после загрузки сделана ещё одна и проверено её восстановление в отдельной новой базе.

## Что доступно

- **«Данные Excel»**: все 835 распознанных строк недельных состояний из 18 листов. Поиск, выбор недели, исходные номера C/D/E, комментарии, суммы, предупреждения и источник до строки. Выгрузка всех доступных состояний в Excel.
- **«Журнал заявок»**: 62 карточки по однозначным совпадениям менеджера, непустого номера C, заказчика и даты, без повторов внутри одной недели. Карточки связаны с 638 исходными состояниями; в карточке можно раскрыть недельные состояния.
- **197 состояний без однозначной карточки**: полностью доступны в «Данных Excel» и недельных отчётах. Записи с пустым/нулевым номером, совпадающие строки одной недели и неполные обязательные данные не объединены автоматически. Это не 197 отдельных уникальных заявок.
- **«Отчёт руководителя»**: остатки и конечные статусы выбранного недельного листа, суммы с расшифровками и разделение по менеджерам. Победы/проигрыши как известное состояние Excel показаны отдельными показателями. Исторические события не выдуманы: событийные победы/проигрыши считают реальные действия приложения.
- **Исходный отчёт**: внизу страницы «Данные Excel» руководителю/администратору доступно 10 166 непустых ячеек исходного сводного листа, включая формулы и сохранённые результаты. Ячейки без результата помечены «Нет кэша».

Для первой недели по требованиям 17 новых заявок; исходный сводный Excel показывает 50 по другому правилу. Для 26.10–30.10 открытый остаток по листу — 48. Будущие листы тоже сохранены, но могут быть шаблонами и не подтверждают будущие события. Пустая дата и прочие пропуски остаются неизвестными.

## Доступ

Существующие `test.admin` и `test.head` видят весь отдел. `test.manager` для проверки представляет первого менеджера из книги и видит только его данные (70 недельных состояний). Пароли существующих тестовых аккаунтов не менялись. Остальные имена заведены как отключённые профили с непредсказуемыми паролями; сотрудники не подключены. Редактор может сохранить карточку с прежним отключённым ответственным; для назначения нового ответственного требуется активный менеджер.

## Проверки

28 автоматических тестов проходят. Дополнительно прямыми HTTP-запросами проверены все 18 недель, 835 строк без потерь источника, суммы/количества против расшифровок, равенство общего итога сумме менеджеров, изоляция менеджера, запрет чужой карточки, исходный отчёт и экспорт. Повторный запуск импорта не создаёт новых записей.

Проверено восстановление 10 пользователей, 62 карточек, 62 записей импорта в истории, всех 835 наблюдений и 10 166 ячеек отчёта в отдельную новую базу. Результаты и полная ведомость конфликтов сохранены только в `.local/full-import-result.json`, `.local/full-import-verification.json`, `.local/full-import-backup-verification.json`.

Для воспроизводимого локального запуска импорта есть `npx.cmd tsx scripts/import-all-local.ts '..\Отчет_ЗРА_ТЕСТОВЫЙ.xlsx'`. Это специальная команда для предоставленной тестовой книги 2026 года, а не универсальная загрузка любого исторического архива. Она ограничена локальной установкой и сохраняет реальные моменты импорта отдельно от недельных состояний. Не используйте её для неподтверждённой производственной миграции.

Отмена возможна штатной командой `import:rollback` с ID из ведомости; после редактирования карточек команда откажется удалять их. При отмене сначала архивируются карточки, недельные наблюдения и исходный отчёт в `.local`, затем удаляются только данные этого импорта. Для полного возврата к состоянию до загрузки используйте резервную копию в отдельной базе. Созданные отключённые профили при отмене остаются для прозрачности системного журнала.
